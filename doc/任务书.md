## 一、项目背景与核心问题

### 1.1 背景

西北荒漠"丝路电力走廊"的巡检困局：海量风力发电场和超高压输电线路分布在无5G/4G覆盖的荒漠中，沙丘地形、空气扰动、电磁干扰使得传统单机巡检面临巨大风险。

### 1.2 三个核心矛盾

1. **探索vs任务**：初始地图仅有带5-10m偏移的粗糙卫星先验，无人机必须权衡"先探索建图修正定位"与"直接执行巡检任务"
2. **任务与寿命**：4架无人机在有限电池电量内，完成风机（点）和电缆（线）的动态巡检
3. **分布与协同**：2组×2架无人机在分布式架构下，实现小组内分工协同与组间任务调度

### 1.3 不做的事

- ❌ 通信中继（不做多跳通信拓扑维持）
- ❌ 光伏阵列巡检（不做"面"任务）
- ❌ 视觉SLAM（不用相机做定位）
- ❌ 从零写算法（只做集成适配，全部用成熟方案）

## 二、技术决策总表

| 项目 | 决策 | 备注 |
|------|------|------|
| 多机架构 | 2组×2架，小组内分工协同 | 电缆一左一右，风机螺旋+悬停 |
| 任务类型 | 风机(点)+电缆(线) | 不要光伏(面) |
| 任务生成 | 随机生成任务，实体可固定 | 任务候选列表+RL选择 |
| 感知定位 | 先GT+漂移+探索修正 | 后期换SLAM |
| 建图 | LiDAR建图+OctoMap | 训练用numpy等价，验证用真实OctoMap |
| 地图熵 | 体素级H(v)公式 | 扇区采样8方向编码进RL观测 |
| RL输出 | 速度指令[vx,vy,vz,yaw_rate] | 残差RL：规则引导+RL修正 |
| 训练环境 | Python训练+Gazebo定期验证 | 每500K步验证一次 |
| 覆盖评估 | 距离阈值判定 | 训练简化，验证可加视锥体 |
| 无人机动力学 | 简化四旋翼(一阶响应+阻力) | 参数从PX4阶跃响应拟合 |
| 电缆模型 | 抛物线近似 | 与Gazebo一致 |
| 风机模型 | 简化圆柱体 | 塔身+顶部检测点 |
| 风场模型 | 稳态风+湍流 | 阵风后期课程加入 |
| 碰撞检测 | 含地形heightmap | 地面+风机+电缆+队友 |
| 防碰撞 | 奖励惩罚+动作裁剪 | 70%原始+30%修正 |
| MARL框架 | Ray RLlib | MAPPO实现 |
| 课程学习 | 单机→2机→4机+约束 | 阶段3约束逐步加入 |
| 协同机制 | 混合：规则分配角色，RL学执行 | 角色标签作为观测输入 |
| Actor | 按组共享参数 | 同组共享，不同组独立 |
| Critic | 层次注意力 | 组内→组间 |
| 奖励函数 | 覆盖+降熵+OED定位不确定性+防碰撞+功耗+低电量预警 | |
| 共享地图 | OctoMap体素更新(50m/每10步)+目标修正坐标 | 点云本地保留不共享 |
| 电量 | 消耗模型(速度+爬升+抗风+机动) | 回基站瞬间满电(换电池) |
| 低电量 | <15%规则强制返航 | RL学15%以上的权衡 |
| 可视化 | Gazebo+rviz2+matplotlib | |
| 日志 | Markdown+Python logging | |

            battery,                       # 电量 [0,1]

            coverage_progress,             # 当前目标覆盖进度 [0,1]

            role_primary,                  # 1=主, 0=辅
            group_id,                      # 0=组A, 1=组B

            # 地图信息 (9维)
            entropy_sector_0..7,           # 8扇区地图熵
            target_direction_entropy,      # 目标方向平均熵

            # 定位不确定性 (1维)
            pose_uncertainty,              # trace(Σ_pose) 归一化值
        ]
        总维度: 7 + 1 + 4 + 2 + 9 + 1 = 24

    动作空间 (单架无人机):

            task_select,                   # [0, N_tasks) 任务选择索引
        ]
        总维度: 5
    """

    def reset(self, seed=None, options=None) -> Tuple[obs_dict, info]:
        """
        Returns:
            obs_dict: {agent_id: obs_array}  多智能体观测字典
            info: {}
        """

    def step(self, action_dict) -> Tuple[obs_dict, reward_dict, terminated_dict, truncated_dict, info_dict]:

        Args:
            action_dict: {agent_id: action_array}

        Returns:
            obs_dict: {agent_id: obs_array}
            reward_dict: {agent_id: float}

### 7.3 奖励函数接口

```python
def compute_reward(
    prev_state: dict,
    curr_state: dict,
    action: np.ndarray,
    info: dict,
    phase: int,          # 课程阶段 1/2/3
) -> float:
    """
    奖励函数（按课程阶段启用不同项）

    阶段1:
        R = w1 * Δ_coverage - w3 * collision - w4 * power

    阶段2:
        R = w1 * Δ_coverage + w5 * cooperation - w3 * collision
          - w4 * power - w6 * intra_collision

    阶段3:
        R = w1 * Δ_coverage           # 任务覆盖
          + w2 * (-Δ_avg_entropy)     # 地图降熵
          + w2b * (-Δ_trace_Σ_pose)   # OED定位改善
          + w5 * cooperation           # 协同奖励
          - w3 * collision             # 碰撞惩罚
          - w4 * power                 # 功耗惩罚
          - w6 * intra_collision       # 组内碰撞
          - w7 * low_battery           # 低电量预警
          - w8 * battery_death         # 电量耗尽
          + w9 * Δ_battery_charge      # 充电奖励
    """
```
